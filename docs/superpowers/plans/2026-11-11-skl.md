# skl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `skl`, a Python CLI with zsh and bash completion that indexes command-style Claude skills locally, validates input, and runs them through the `claude` CLI or the Claude app.

**Architecture:** One standard-library Python file, `skl/skl`, holds the parser, the store, validation, the completion engine and the runner. Shell completion scripts are string constants inside it, printed by `skl completion`, and call `skl __complete` for candidates. Everything reads one JSON index under the data directory.

**Tech Stack:** Python 3.9+ standard library, `unittest`, bash, zsh, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-11-skl-design.md`. Read it before starting any task.

**Execution:** Implementer subagents run on the Sonnet model, one task each, in order. Tasks 1 to 8 need no network and no GitHub access. Task 9 is run by the controlling session, not a subagent.

## Global Constraints

- Python 3.9 or newer. Start `skl/skl` with `#!/usr/bin/env python3` and `from __future__ import annotations`. No `match` statements, no third-party packages.
- `skl/skl` is one file with no `.py` extension, mode 755.
- Store: `${XDG_DATA_HOME:-~/.local/share}/skl/`, containing `skills/<name>/SKILL.md` and `index.json`.
- Exit codes: 0 success, 1 general error, 2 usage error, 127 `claude` not on PATH.
- All error output goes to stderr and starts with `error: `. No Python traceback may reach the user: `main` catches `SklError` and `OSError`.
- bash completion must work in bash 3.2: no `mapfile`, no associative arrays, no `${var,,}`.
- Tests: `cd skl && python3 -m unittest discover -s tests -v`. No network, no real `claude` binary.
- Commit after every task. End each commit message with the two attribution lines the session provides.
- Work on branch `main` in `/home/claude/claude-tools`. Do not push; Task 9 publishes.

## Review Focus

1. A skill whose name is unsafe as a folder name (`../x`, contains `/`, `:` or spaces) is refused with an error, and nothing is written outside the store. Test in Task 3.
2. A `SKILL.md` with CRLF line endings, a fence with an info string (```` ```text ````), or bytes that are not UTF-8: the first two still parse, the third is skipped with a `skipped` note and `sync` carries on. Tests in Tasks 1 and 3.
3. Arguments with spaces, double quotes, `$`, a value that starts with `-`, and the `--flag=value` form reach `claude` as one intact command string. Tests in Tasks 4 and 5.
4. Completion with a missing or corrupt index, or an unknown skill, prints nothing and exits 0 with empty stderr. Test in Task 6.
5. `sync` that finds no skills keeps imported entries, and the same skill name in two sources leaves one entry plus a `note:` line. Test in Task 3.

## Shared definitions

Every task uses these. Names and shapes are fixed.

```python
class SklError(Exception): ...            # exit 1, message printed as "error: <msg>"
class UsageError(SklError): ...           # exit 2, carries .usage_line (str or None)

# Interface (JSON-serializable)
{"usage_line": str,
 "actions": {name: {"targets": [{"name": str, "required": bool}], "description": str}},  # insertion order kept
 "groups": [{"label": str, "actions": [str] or None, "flags": [Flag]}]}                  # None = every action
# Flag
{"names": [str, ...], "takes_value": bool, "choices": [str, ...]}

{"version": 1, "skills": {name: Entry}}
# Entry
{"name": str, "source": "sync" or "import", "source_path": str,
 "usage_block": str, "interface": Interface or None}      # None = pass-through
```

### Task 1: Scaffold, test harness, block extraction, actions

**Files:**
- Create: `skl/skl`, `skl/tests/__init__.py`, `skl/tests/helpers.py`, `skl/tests/test_parser.py`, `skl/tests/fixtures/notes/SKILL.md`, `.gitignore` (`__pycache__/`)

**Interfaces:**
- Produces in `skl/skl`:
  - `extract_block(skill_md: str) -> str | None`: text inside the first fenced block after a heading line matching `^##\s+Command interface` (case-insensitive), without the fence lines. `None` if there is no such heading or no fence before the next `## ` heading. Fences are lines starting with three backticks or three tildes; an info string after the opening fence is allowed. CRLF input is normalised to LF first.
  - `frontmatter_name(skill_md: str) -> str | None`: the `name:` value from a leading `---` frontmatter, quotes stripped.
  - `parse_interface(block: str) -> dict | None`: in this task fills `usage_line` and `actions`, with `groups` as `[]`. Returns `None` when no action is found.
  - `main(argv: list[str]) -> int` and the `if __name__ == "__main__": sys.exit(main(sys.argv[1:]))` guard. For now `main` returns 2 after printing `error: unknown command` for anything.
- Produces in `skl/tests/helpers.py`:
  - `SKL_PATH: pathlib.Path` (absolute path of `skl/skl`), `FIXTURES: pathlib.Path`.
  - `load_skl()`: imports the file as a module with `importlib.machinery.SourceFileLoader("skl", str(SKL_PATH))`, cached.
  - `class SklCase(unittest.TestCase)`: `setUp` makes a temp dir with `home/`, `data/`, `bin/`, `work/`; `self.env` is a dict with `HOME`, `XDG_DATA_HOME=<tmp>/data`, `PATH=<tmp>/bin:/usr/bin:/bin`, `SKL_STUB_LOG=<tmp>/stub.log`; `self.run_cli(*args, cwd=None, env=None) -> subprocess.CompletedProcess` runs `[sys.executable, str(SKL_PATH), *args]` with `capture_output=True, text=True`, cwd defaulting to `work/`.
  - `SklCase.make_stub(name: str, exit_code: int = 0)`: writes an executable shell script `bin/<name>` that appends each argument on its own line to `$SKL_STUB_LOG`, then a line `--END--`, and exits with `exit_code`.
  - `SklCase.put_skill(root: pathlib.Path, fixture: str, folder: str | None = None) -> pathlib.Path`: copies `fixtures/<fixture>/SKILL.md` to `root/<folder or fixture>/SKILL.md` and returns that path.

Action parsing rules: the usage line is the first line starting with `/`. The actions section starts at a line starting with `Actions` and ends at the first following line that is blank or not indented. In it, each indented line whose first word matches `^[a-z][a-z0-9-]*$` is an action; following words of the form `<x>` are required targets and `[<x>]` optional targets (target name is `x`); the description is the remainder with surrounding whitespace stripped.

### Task 2: Option groups and flags

**Files:**
- Modify: `skl/skl` (`parse_interface`), `skl/tests/test_parser.py`
- Create: `skl/tests/fixtures/meal/SKILL.md`

**Interfaces:**
- Consumes: `parse_interface`, `extract_block` from Task 1.
- Produces:
  - `parse_interface` now fills `groups`.
  - `flags_for(interface: dict, action: str) -> list[dict]`: flags of every group whose `actions` is `None` or contains `action`, in block order, de-duplicated by `names[0]`.
  - `all_flag_names(interface: dict) -> set[str]`: every name of every flag in every group.

Group parsing rules, applied to the lines after the actions section:

1. A line matching `^\s*([A-Za-z][^:]*?):\s*(.*)$` whose captured label contains no `--` starts a group. The remainder of the line is its first flag text.
2. An indented line whose first non-space character is `-` continues the current group.
3. Other lines are ignored.
4. Label to actions: label `Global` (case-insensitive) gives `None`. If the label has a parenthesised part, split its inside on `/` and `,`; if every piece is a known action, those are the actions. Otherwise split the whole label on `/` and `,`; if every piece is a known action, those. Otherwise `None`.
5. Flag text: remove every parenthesised span, then tokenise with the regex `"[^"]*"|\S+`. A token matching `^--?[A-Za-z][A-Za-z0-9-]*$` is a flag name. A `|` token between two flag names makes the second an alias of the first. A token directly after a flag name that starts with `<` or `"<` is its value placeholder and sets `takes_value`. If the placeholder is exactly `<a|b|...>` with at least two parts that all match `^[A-Za-z0-9_-]+$`, those parts are `choices`.

### Task 3: Store, sync, import, list, show, remove

**Files:**
- Modify: `skl/skl`
- Create: `skl/tests/test_store.py`

**Interfaces:**
- Consumes: `extract_block`, `frontmatter_name`, `parse_interface`.
- Produces:
  - `store_dir() -> pathlib.Path`, `load_index() -> dict` (returns `{"version": 1, "skills": {}}` when the file is missing; raises `SklError("index is unreadable, run 'skl sync'")` when it is not valid JSON), `save_index(index: dict) -> None` (writes to a temp file in the same directory, then `os.replace`).
  - `make_entry(skill_md_path: pathlib.Path, source: str) -> dict`: builds an Entry. Name is `frontmatter_name`, else the first word of the usage line without `/`, else the parent folder name. Raises `SklError` when the file is not UTF-8, has no command interface block, or the name does not match `^[A-Za-z0-9][A-Za-z0-9._-]*$`.
  - `scan_roots(cwd: pathlib.Path) -> list[pathlib.Path]`: `~/.claude/skills`; then `.claude/skills` in each directory from the git root (nearest ancestor containing `.git`) down to `cwd`, or only `cwd` when there is no git root; then each entry of `SKL_SKILL_PATH` (split on `os.pathsep`). Missing directories are left out.
  - `get_entry(index: dict, name: str) -> dict`: raises `UsageError("unknown skill '<name>'")`; when `difflib.get_close_matches(name, skills, n=3)` finds any, the message gets a second line `did you mean: a, b`.
  - `main` dispatch for `sync`, `import`, `list`, `show`, `remove`, and the top-level `try/except` that prints `error: <msg>` and returns 1 for `SklError`/`OSError`, 2 for `UsageError`.

Behaviour:
- `skl sync`: for every `SKILL.md` under each root (`rglob`, sorted), call `make_entry`; on `SklError` for a missing interface block, skip silently; for any other `SklError`, print `skipped <path>: <reason>` to stderr. Copy the file to `skills/<name>/SKILL.md`. Print `indexed <name> (<n> actions)` or `indexed <name> (pass-through)`. When a name appears twice, the later one wins and prints `note: <name> from <new path> replaces <old path>`. Then drop `sync` entries not seen this run, printing `removed <name>`, and delete their store folders. Imported entries stay untouched unless a synced skill has the same name, in which case the synced one replaces it with the same `note:` line. Last line: `<n> skills indexed` (total in index).
- `skl import <path>`: path may be a `SKILL.md`, a folder containing one, or a zip (`.skill` or `.zip`). For a zip, read the member named `SKILL.md` or `<one-folder>/SKILL.md` straight from the archive with `ZipFile.read`; never call `extract`/`extractall`. No such member: `error: no SKILL.md in <path>`. A skill without an interface block is an error here. Stores with `source: "import"`, prints `imported <name>`.
- `skl list`: one line per skill sorted by name: `<name>\t<actions joined by ", ">` or `<name>\t(pass-through)`. Empty index: prints `no skills indexed, run 'skl sync'`, exit 0.
- `skl show <skill>`: prints `usage_block` verbatim. `--parsed` prints `json.dumps(interface, indent=2)`.
- `skl remove <skill>`: deletes the entry and its store folder, prints `removed <name>`; for a `sync` entry also prints `note: 'skl sync' will add it back while the source exists`.

### Task 4: Validation

**Files:**
- Modify: `skl/skl`
- Create: `skl/tests/test_validate.py`

**Interfaces:**
- Consumes: `flags_for`, `all_flag_names`, `UsageError`.
- Produces: `validate(entry: dict, args: list[str]) -> None`. Raises `UsageError(msg)` with `usage_line` set to the interface's usage line. Returns without checking when `entry["interface"]` is `None`. Does not handle `--help`; the caller does (Task 5).

Rules, in this order while walking `args` left to right:

| Condition | Message |
|---|---|
| no args, or first arg starts with `-` | `missing action` |
| first arg not an action | `unknown action '<x>'` |
| arg starting with `-` (split at the first `=` if present) whose name is in no group of the skill | `unknown flag '<f>'` |
| flag known to the skill but not in `flags_for(action)` | `flag '<f>' is not valid for '<action>'` |
| value-taking flag with no `=value` and no next arg | `flag '<f>' needs a value` |
| non-value flag written as `--f=v` | `flag '<f>' takes no value` |
| positional beyond the action's declared targets that is an action name | `second action '<x>'` |
| any other positional beyond the declared targets | `unexpected argument '<x>'` |
| after the walk, fewer positionals than required targets | `missing <target-name> for '<action>'` |

### Task 6: Completion engine

**Files:**
- Modify: `skl/skl`
- Create: `skl/tests/test_complete.py`

**Interfaces:**
- Consumes: `load_index`, `flags_for`, `all_flag_names`.
- Produces:
  - `complete(index: dict, words: list[str]) -> list[tuple[str, str]]`: `(candidate, description)` pairs. `words` are the command-line words after `skl`; the last one is the word being completed and may be `""`. Only candidates that start with the last word are returned.
  - `skl __complete -- <words...>` prints each pair as `candidate\tdescription` (no tab when the description is empty). It always exits 0 and prints nothing on stderr; any exception gives empty output.

Rules:

- One word: built-in names (description `""`), then indexed skill names sorted.
- First word `show`, `remove` or `run`, completing word two: skill names. For `run`, drop the first word and continue as a skill line.
- First word `completion`, completing word two: `zsh`, `bash`.
- First word is an indexed skill:
  - completing word two: its actions with their descriptions, in block order. Pass-through skill: `--help`, `--print`, `--app`.
  - later, when the action is unknown: nothing.
  - later, when the previous word is a value-taking flag valid for the action: its `choices`, or nothing when it has none.

- Anything else: nothing.

_skl_complete() {
  local line
  COMPREPLY=()
  while IFS= read -r line; do
    [ -n "$line" ] && COMPREPLY+=("${line%%$'\t'*}")

_skl() {
  local -a out cands
  local line name desc
  out=("${(@f)$(skl __complete -- "${(@)words[2,CURRENT]}" 2>/dev/null)}")
  for line in $out; do
    [[ -z $line ]] && continue
    name=${line%%$'\t'*}
    desc=""
    [[ $line == *$'\t'* ]] && desc=${line#*$'\t'}
    name=${name//:/\\:}
    if [[ -n $desc ]]; then cands+=("$name:$desc"); else cands+=("$name"); fi
  done
  if (( ${#cands} )); then _describe -t skl 'skl' cands; else _files; fi
